# Proyecto de Análisis de Ventas - DN4 Brands

Análisis automatizado de ventas de Mercado Libre usando Python y pandas.

## Tecnologías
- Python 3.12+
- pandas
- uv (gestor de paquetes)

## Uso

```bash
uv run main.py
```

## Resultados
- Total de ventas analizadas: 14,293
- Ingresos totales: $3.8M MXN
- Top SKU: OBYMMG5CAP180 (1,173 unidades)
